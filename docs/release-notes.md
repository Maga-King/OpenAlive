0.4.28-preview：修复小米地球高分辨率设备冷启动加载失败。

- 地球原版引擎在屏幕高度超过 2400 px 时请求固定渲染尺寸；系统壁纸窗口拒绝时，改用系统布局尺寸，并继续把真实窗口大小传给引擎。
- 初始化失败会解除临时窗口回调，避免后续重试遗留回调。手动 dumpsys 可查看地球原生渲染状态，不增加轮询日志。

0.4.27-preview：修复 Vivo 换图后动效范围无法打开，优化双指裁切。

- 图片和视频列表使用一致的配置序列化，避免刚导入的液态／闪卡素材被误判为过期编辑结果。
- 连续双指操作合并为最新裁切；松手后再更新液态蒙版网格，保存裁切不再重建整个场景。普通单指触摸不会触发裁切重算。

- 「封面图片/视频」「光栅图片/视频1」「光栅图片/视频2」可任意混搭图片和循环视频，各自裁切、旋转；交换位置同时保留素材的编辑参数。批量选图按返回顺序填入最多三个位置，感应视频保留独立入口。
