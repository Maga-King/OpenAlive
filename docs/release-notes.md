修复壁纸应用、魅族动态壁纸衔接与 Vivo 光栅素材和色彩显示。

- 每次点击应用都进入系统壁纸选择器，避免桌面已使用同一服务时跳过锁屏应用。指定预览无法启动时，依次尝试动态壁纸列表、系统壁纸入口和壁纸/主题应用普通入口。
- 取消选择器保留编辑内容，不误报应用成功；补充独立锁屏和页面重建后的返回处理。
- 魅族 Cosmic、Phoenix 和气泡壁纸隐藏时暂停过渡时间，恢复和反向切换从当前画面继续；显示电源状态变化时重新挂接帧调度，保留原版动画曲线。
- Vivo 图集光栅支持封面加一至两张图片；替换封面时保留完整默认三张。
- Vivo 默认素材保留 Display P3 色域，照片按实际输出色域转换；不支持相应 EGL 输出时转换到 sRGB，修复色域信息丢失造成的颜色偏差。
