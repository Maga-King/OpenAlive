OpenAlive 的首个公开预览版。

- 支持启航、留光、星月、轻启、山脉、银河与自选照片。
- 留光支持相框独立取景、旋转，以及息屏时间、日期和农历。
- 修正桌面时钟干扰息屏位置追踪的问题。
- 应用更名为 OpenAlive，包名保持 `org.aliveclean`，已有版本可覆盖安装。

需要 Root + LSPosed，主要适配 ColorOS 17。安装后启用模块并重启手机。

APK 由本仓库 GitHub Actions 编译、签名并检查资源对齐；附件提供 SHA-256 校验值。宿主及渲染库由源码编译，官方 UI 使用仓库内的预编译组件。云端编译通过不代表所有设备均已实测。

部分资产来源于魅族22FlymeOS。自实现代码采用 MIT，官方 UI 和素材保留原有权利。
