这版把魅族和澎湃时钟接进了 ColorOS 系统锁屏编辑器，也补齐了它们与留光的配合。

- 新增 21 款时钟样式及配套字体，支持预览、保存与重启后恢复。
- 支持颜色、质感、柔和渐变与特殊效果，可恢复默认颜色。
- 修复切换时钟或调整颜色后，应用按钮不响应修改的问题。
- 修复新增时钟在留光息屏和指纹直接解锁时遮挡相框的问题，保留系统小组件。
- 改善时钟衔接、小组件布局和编辑预览的兼容性。

需要 Root + LSPosed，主要适配 ColorOS 17。作用域勾选系统框架、系统界面和壁纸与个性化（`com.oplus.wallpapers`）。覆盖安装后请正常重启手机并解锁一次，让 SystemUI 加载新版模块。不同系统版本仍可能存在差异。

APK 由 GitHub Actions 从本次提交编译、签名，并检查资源表未压缩及 4096 字节对齐。附件提供 SHA-256 和构建报告。宿主与渲染库由源码编译；官方 UI 与部分时钟使用仓库内的预编译组件。

部分资产来源于魅族22FlymeOS，另含澎湃系统时钟资源。自实现代码采用 MIT；官方组件和素材保留原有权利，详见仓库资源说明。
