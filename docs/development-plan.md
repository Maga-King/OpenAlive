壁纸来源分为 **Alive 动态壁纸 / 魅族静态壁纸 / 自选照片**。动态壁纸按官方名称选择，仍使用现有三态编辑器；照片的取景、纹理和配对配置保留。

留光只替换息屏时钟。新增 Cosmic 使用系统时钟，不套用留光的隐藏策略。普通锁屏、小组件内容、指纹区域以及已确认的小球定位逻辑不在这次改动范围内。

测试包为 `OpenAlive-0.4.18-cosmic-test1.apk`，已安装备用机。外层和内嵌 UI 的资源表均未压缩且按 4096 字节对齐。原有 Rust 渲染库和官方 UI DEX 保持原样。
