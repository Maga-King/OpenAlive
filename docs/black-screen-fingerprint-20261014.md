# 黑屏指纹与下一次息屏（本地待实机验证）

指定设备 `3B1F4UE5MS13HQRR` 的系统事件显示：黑屏指纹返回应用时，快速解锁分支提前退出 AOD，遥控动画目标为空；下一次息屏会先重放 `uiState=1, clockSize=11`，再送达 `uiState=5, clockSize=1`。从桌面解锁和从应用解锁不能视作同一条系统动画路径。

公共时钟插件现在把 UNLOCK 视为隐藏态，保留上一次可见面的尺寸，不把隐藏态转换成大锁屏面；下一次可见状态恢复对应时钟。所有继承该插件的魅族、澎湃、vivo 时钟共享修复。

公共指纹 Hook 在选中 OpenAlive 壁纸、黑屏、仍处于 dreaming 且锁屏未退出时，调用系统已注册的单击 AOD 回调。遵守 AOD 开关、接近和倒置条件。该请求后 600 ms 内原生全景 AOD 显示动画的遮罩使用 160 ms 线性过渡、无启动延迟。保留原生监听器、屏幕请求和唤醒取消逻辑，不改认证结果、不伪造本地 HBM 能力、不阻塞解锁线程。普通触摸抬起、认证失败继续由系统处理。

这条公共 Hook 对壁纸家族不作区分，但尚未在 SystemUI 中加载验证。尤其快指纹认证可能赶在 AOD 显示前结束 dreaming；当前实现没有人为延迟认证或保证 AOD 先画完。需要安装同签名包并重载模块后，核对应用/桌面两条路径及真实屏幕效果，不能以独立时钟测试代替。

验证：指定设备上的独立容器通过全部 63 款注册时钟、567 组循环，包括锁屏/两种 AOD 来源、三种尺寸、重复 UNLOCK(size 11)、重复 AOD、快速反转和迟到回调。原生时钟传输测试通过。测试包已自动卸载，未覆盖主应用。
